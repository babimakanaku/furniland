# Furniland — Furniture E-Commerce Website

## Overview
Furniland is a furniture e-commerce website developed as an academic project. It provides a platform for users to explore furniture products and manage shopping transactions.

## Key Features
- Product catalog and product details
- Shopping cart and checkout
- Transaction history
- Admin dashboard and data management

## Technologies
- PHP
- MySQL
- HTML, CSS, and JavaScript

## Getting Started
1. Install a local PHP and MySQL development environment.
2. Import the provided SQL database into MySQL.
3. Configure the database connection using your local settings.
4. Run the project through your local web server.
